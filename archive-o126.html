핵심 요약
  • AI 튜터 사용 기록⁠(학생 34⁠명의 평균 풀이 시간, 풀이 이미지 2,712⁠장)⁠과 기능 평가 설문⁠(10⁠명)⁠으로 학습 참여 양상을 살핀 10⁠월 리포트

보고서 소개

"⁠선형대수학 AI 튜터 학습 데이터를 활용한 AI 튜터 성능 향상 연구"⁠의 10⁠월 정기 리포트다.
9⁠월 리포트가 시험 성적 분포와 문항별 성취 특성을 다뤘다면, 이번에는 AI 튜터 사용 기록과 학생의 실제 제출물로 학습 참여 양상을 파악하고, 학생이 인식한 서비스의 장점과 개선 요구를 함께 검토해 이후 학습 지원 기능 분석의 기초 자료를 마련한다.

풀이 시간의 요약 통계와 구간별 분포, 이미지의 과제⁠·⁠자율학습 구성과 월별 분포, 기능 평가 항목별 평균⁠·⁠표준편차와 4⁠~⁠5⁠점 응답 수를 산출하고 주관식 의견을 장점⁠·⁠개선점별로 분류했다.

주요 분석 결과

  • 학생별 평균 풀이 시간⁠(34⁠명)⁠은 평균 7⁠분 26⁠초, 중앙값 6⁠분 06⁠초, 최소 1⁠분 29⁠초에서 최대 18⁠분 36⁠초까지 17⁠분 넘게 차이가 났다.
  • 5⁠분 미만 11⁠명⁠(32.4%), 5⁠~⁠10⁠분 17⁠명⁠(50.0%)⁠으로 82.4%⁠가 10⁠분 미만이었고, 10⁠~⁠15⁠분과 15⁠분 이상이 각 3⁠명⁠(8.8%)⁠이었다.
  • 풀이 이미지 2,712⁠장 중 과제 제출 1,989⁠장⁠(73.3%), 자율학습 723⁠장⁠(26.7%).
    파일명 기준 정답 표기 2,203⁠장⁠·⁠오답 509⁠장⁠(문제별 정답률은 아님).
  • 이미지 수 상위 5⁠명⁠(166⁠·⁠159⁠·⁠142⁠·⁠137⁠·⁠114⁠장)⁠이 전체의 26.5%⁠를 차지했고, 저장 월은 4⁠월 32.3%, 5⁠월 31.9%, 6⁠월 22.9%, 3⁠월 12.9% 순이었다.
  • 기능 평가⁠(10⁠명, 5⁠점 만점)⁠는 AI 활용성 4.80⁠점, 전반 만족도 4.60⁠점, 편의성 4.30⁠점, 인식률 4.20⁠점이었다.
  • 주관식에서 강점은 "⁠필기⁠·⁠사진 기반 입력"⁠과 "⁠즉각적인 학습 피드백", 개선 요구는 필기 인식 지연⁠·⁠풀이 공간 부족⁠·⁠태블릿 펜 지연⁠(입력 편의), 행렬 입력 버튼⁠·⁠실행 취소 구분⁠(수식 입력⁠·⁠화면), 부분 점수⁠·⁠채점 근거⁠·⁠이전 질문 기록⁠·⁠오답 기반 복습⁠(채점⁠·⁠개인화)⁠으로 분류됐다.

시사점과 제언

  • 풀이 시간은 문항별 시작⁠·⁠제출 시각과 비활동 시간을 분리 저장하고, 문항 ID⁠·⁠시도 ID⁠·⁠이미지 ID⁠를 나눠 중복 집계를 막는다.
  • 행렬 입력 도구⁠·⁠캔버스 확장⁠·⁠펜 입력 최적화로 손글씨⁠·⁠수식 입력을 개선하고, 단계별 오류 표시와 부분 점수 기준을 안내한다.
  • 누적된 학습 경향과 풀이 기록을 취약 개념 복습⁠·⁠이전 질문 이력⁠·⁠오답 재학습과 연결해 개인별 학습을 지원한다.
  • 풀이 시간이 요약값이고 이미지 수가 해결 문항 수와 다르며 설문 표본⁠(10⁠명)⁠이 별도라는 한계가 있어, 이번 리포트는 참여 현황의 기준선 분석이다.
    11⁠월에는 답안 수정⁠·⁠재제출, 힌트 요청, 챗봇 질문 이력을 학생⁠·⁠문항 단위로 연결해 분석할 계획이다.
