GitHub 토큰으로 들어갑니다.

이 사이트의 글은 GitHub 저장소⁠(yoong0520/keli⁠-⁠site)⁠의 파일에 저장되고, 저장하면 1⁠~⁠2⁠분 뒤 자동으로 배포됩니다.
토큰은 이 브라우저에만 저장되고 GitHub 외에는 어디에도 전송되지 않습니다.

토큰 만드는 방법
첫 관리자 계정 만들기 (서버를 처음 연결했을 때 한 번)
관리자 서버 주소 바꾸기⁠(이 브라우저에만)
현재: —
토큰 만드는 방법 (한 번만)
  1. GitHub 로그인 → 오른쪽 위 프로필 → Settings → 왼쪽 맨 아래 Developer settings → Personal access tokens → Fine⁠-⁠grained tokens → Generate new token
  2. Token name: KELI 관리자 / Expiration: 1⁠년⁠(또는 원하는 기간)
  3. Repository access: Only select repositories → yoong0520/keli⁠-⁠site 선택
  4. Permissions → Repository permissions: Contents: Read and write, Actions: Read and write (나머지는 그대로)
  5. Generate token → 나온 문자열⁠(github_pat_⁠…⁠)⁠을 위 칸에 붙여 넣기

저장소가 다른 사람 소유이면 그 사람이 내 계정을 저장소 Collaborator⁠(Write)⁠로 먼저 초대해야 합니다.
토큰을 잃어버리면 같은 방법으로 새로 만들면 됩니다.
