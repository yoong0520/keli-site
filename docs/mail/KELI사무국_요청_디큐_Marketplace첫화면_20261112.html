한림대학교 KELI 사무국(AI교육혁신원 AI교육확산센터)입니다.
지난 협의에서 말씀 나눈 대로, KELI는 앞으로 두 사이트로 역할을 나누어 운영하려 합니다. 서비스 소개·사례·연구 자료 같은 정보 제공은 새 KELI 플랫폼(keli-aied.org)이 맡고, 기존 KELI 포털(keliedu.org)은 솔루션 데모 신청·도입·구독이 이루어지는 KELI Marketplace로 운영합니다. 이에 맞추어 사이트명·설명·키워드는 관리자 화면에서 사무국이 직접 바꾸었습니다.

다만 첫 화면(메인)의 큰 제목과 소개 문구는 관리자 화면의 컨텐츠관리에 없고 화면 틀(템플릿) 파일에 들어 있어, 웹파일관리 계정이 없는 사무국에서는 고칠 수 없었습니다. 아래 두 가지 가운데 편하신 방법으로 도와주시기를 부탁드립니다. 화면 구조나 기능을 바꾸는 작업이 아니라 글귀만 바꾸는 작업입니다.
요청 1  아래 표의 첫 화면 문구 교체(디큐에서 직접 반영)
또는 요청 2  사무국이 직접 고칠 수 있도록 웹파일관리 계정(아이디·임시 비밀번호) 안내
