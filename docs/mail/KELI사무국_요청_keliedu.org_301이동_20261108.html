한림대학교 AI교육혁신원 KELI 사무국입니다.
KELI 플랫폼이 새 주소 https://keli-aied.org 로 개편되어 2026년 11월부터 운영 중입니다. 그동안 운영해 주신 기존 포털(https://keliedu.org, 제목 「KELI 포털 시스템」)이 아직 함께 열려 있어, 구글에서 "한림대학교 KELI"를 검색하면 옛 포털이 첫 번째로 나오고 새 플랫폼은 보이지 않는 등 두 사이트가 나뉘어 나오고 이용자가 옛 주소로 들어가는 일이 생기고 있습니다.

이에 기존 포털의 웹 주소 전체를 새 플랫폼으로 301(영구 이동) 처리해 주시기를 요청드립니다. 301로 옮기면 이용자가 옛 주소를 눌러도 새 플랫폼으로 바로 이동하고, 검색엔진도 옛 주소의 검색 신뢰도를 새 주소로 넘겨 주어 가장 효과가 큽니다.
요청 사항  keliedu.org · www.keliedu.org 의 모든 웹 주소 → https://keli-aied.org 로 301 영구 이동
완료 희망일  2026. 11. 14.(금)까지 · 완료 후 회신 부탁드립니다
유지 기간  최소 1년 이상(검색엔진 반영 기간 고려)
 
설정 내용
대상http(s)://keliedu.org/* 와 http(s)://www.keliedu.org/* 의 모든 경로(하위 페이지 포함)
이동 방식HTTP 301 Moved Permanently (302·메타 새로고침·자바스크립트 이동은 검색 신뢰도가 넘어가지 않으므로 피해 주십시오)
이동 대상기본: 모든 경로 → https://keli-aied.org/ (홈)
가능하시면 아래 경로는 해당 페이지로: /keli/partners/video → https://keli-aied.org/videos.html · /keli 로 시작하는 서비스 소개 → https://keli-aied.org/services.html
HTTPS 인증서keliedu.org 의 SSL 인증서는 유지해 주십시오(https 옛 주소도 오류 없이 이동되어야 함)
바꾸지 말 것메일(MX) 레코드는 그대로 — 사무국 메일 contact@keliedu.org 가 이 도메인으로 운영됩니다. admin.keliedu.org 등 관리용 하위 주소도 사무국과 협의 전에는 유지
방법 예시웹서버(nginx: return 301 https://keli-aied.org$request_uri; / Apache: Redirect permanent / https://keli-aied.org/) 또는 호스팅사의 "도메인 포워딩(301)" 기능. 어느 쪽이든 결과가 301이면 됩니다
※ 확인 방법: 설정 후 브라우저 주소창에 keliedu.org 를 입력하면 keli-aied.org 로 바로 이동해야 하며, 사무국에서도 응답 코드(301)를 확인해 드리겠습니다.
· 옛 포털의 자료(게시글·첨부)는 새 플랫폼으로 이관을 마쳤으므로, 이동 설정 뒤 옛 포털 서비스의 종료 일정은 별도로 협의드리겠습니다.
· 이동 설정에 비용이나 작업 일정이 필요하면 미리 알려 주시기 바랍니다.
