한림대학교 KELI 사무국(AI교육혁신원 AI교육확산센터)입니다.
지난 협의에서 말씀 나눈 대로, KELI는 두 사이트로 역할을 나누어 운영합니다. 서비스 소개·사례·연구 자료는 새 KELI 플랫폼(keli-aied.org)이 맡고, 기존 KELI 포털(keliedu.org)은 솔루션 데모 신청·도입·구독이 이루어지는 KELI Marketplace로 운영합니다.

사무국이 관리자 화면에서 할 수 있는 작업(사이트명·설명·키워드 변경, 상단 메뉴 이름을 새 플랫폼과 맞추고 새 플랫폼으로 연결, 옛 하위 메뉴 숨김)은 이미 마쳤습니다. 남은 작업은 화면 틀(템플릿)과 이미지 파일에 들어 있어 사무국이 고칠 수 없기에, 아래와 같이 요청드립니다.
요청 1  로고 교체 (KELI → KELI | Marketplace)
요청 2  메인 화면을 Marketplace에 맞게 개편
요청 3  바닥글 오타·전화번호·SNS 링크 수정
진행 방법  디큐에서 직접 반영, 또는 사무국이 고칠 수 있도록 웹파일관리 계정 안내
희망 일정  2026. 11. 27.(금)까지 (내부 회의 결과에 따라 협의)
