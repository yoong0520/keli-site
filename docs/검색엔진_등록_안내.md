## 2. 유은님이 하실 것 (각 10분 안팎, 한 번만)

### 2-1. 구글 서치 콘솔
1. https://search.google.com/search-console 에 사무국 구글 계정으로 로그인 → "속성 추가"
2. 두 방법 중 하나
   - (권장) "도메인" 속성에 `keli-aied.org` 입력 → 보여 주는 TXT 값을 복사 → 가비아 My가비아 → 도메인 → DNS 관리 → 레코드 추가: 타입 TXT, 호스트 `@`, 값 `google-site-verification=…` → 저장 → 서치 콘솔에서 "확인"(DNS 반영에 몇 분~1시간)
   - "URL 접두어" 속성에 `https://keli-aied.org/` 입력 → 확인 방법 "HTML 태그" → content 값만 복사 → 관리자 → 사이트 설정 → 인증 코드 칸에 붙여 넣고 "저장하고 게시" → 2분 뒤 서치 콘솔에서 "확인"
3. 왼쪽 "Sitemaps" → `sitemap.xml` 입력 → 제출
4. 위 검색창(URL 검사)에 `https://keli-aied.org/` 입력 → "색인 생성 요청". about.html, services.html, join.html 도 같은 방법으로 요청(하루 10여 건 한도)

### 2-2. 네이버 서치어드바이저
1. https://searchadvisor.naver.com → 네이버 로그인 → 웹마스터 도구 → 사이트 등록: `https://keli-aied.org`
2. 소유 확인 → "HTML 태그" 선택 → `<meta name="naver-site-verification" content="…">` 의 content 값만 복사 → 관리자 → 사이트 설정 → 인증 코드 칸(naver)에 붙여 넣고 저장 → 2분 뒤 "소유확인"
3. 요청 → 사이트맵 제출: `https://keli-aied.org/sitemap.xml`
4. 요청 → RSS 제출은 건너뜀(RSS 없음) · 요청 → 웹 페이지 수집: `https://keli-aied.org/` 와 주요 페이지 주소 입력
5. 검증 → "사이트 간단 체크" 로 robots·사이트맵·메타 태그가 모두 초록불인지 확인
