활용 AI 도구
RAG 기반 생성형 AI, LMS 연계 AI 기능, 자체 코스웨어

본 교과목은 C 프로그래밍을 기반으로 한 AI 코스웨어 활용 실습 중심 교과목으로, 온라인 이론 학습과 대면 실습을 결합한 혼합형⁠(Blended Learning) 방식으로 운영된다.
학습자는 사전 온라인 학습을 통해 기초 개념을 습득하고, 대면 수업에서는 단계별 문제해결 기반 실습⁠(자율 → 안내 → 참조)⁠을 수행한다.
이 과정에서 생성형 AI 및 AI 튜터를 활용하여 코드 작성, 오류 분석, 디버깅을 반복 수행하며, 개인 맞춤형 피드백을 기반으로 학습을 심화한다.

수업 목표

  • C 프로그래밍의 기본 개념⁠(자료형, 제어문, 함수, 배열, 포인터 등)⁠을 이해한다.
  • AI 도구를 활용하여 코드 개선, 오류 수정 및 학습 전략을 수립할 수 있다.
  • 단계별 문제해결 전략을 적용하여 복잡한 문제를 체계적으로 해결할 수 있다.

적용 방법

  1. 학습자 사전진단 — C 프로그래밍 기초 문법 및 논리적 사고력 진단⁠(온라인 퀴즈), AI⁠·⁠디지털 도구 활용 경험 및 자기주도 학습 역량 설문, 학습환경⁠(개발도구, LMS 활용능력) 및 선수지식 수준 분석 (AI 활용: 단계별 문제해결을 위한 AI 활용, 사용자 맞춤형 정보⁠(검색) 제공.
    산출물: 사전학습 결과 분석, 개인별 학습 패턴⁠(경로))
  2. AI 활용 방법 — 온라인 이론학습⁠(강의노트, 동영상 콘텐츠) 기반 사전학습 수행, AI 튜터를 활용한 코드 작성⁠·⁠오류 수정⁠·⁠디버깅 반복 학습, 단계별 문제해결⁠(자율→안내→참조) 기반 실습 진행 (AI 활용: 교과목 챗봇을 통한 실시간 질의응답 및 개념 설명, 학습 로그⁠(코드 시도, 오류, 디버깅 과정) 분석 후 맞춤 힌트 제공.
    산출물: 단계별 문제 해결 코드 및 실행 결과, AI 피드백 반영 전⁠·⁠후 코드 비교 결과)
  3. 학습지원 및 피드백 — 주차별 학습 진행 상황 모니터링 및 학습 참여도 관리, 실습 과정에서 발생하는 오류 및 개념 이해 문제 즉시 피드백, 학습 부진자 대상 보충자료 및 추가 문제 제공 (AI 활용: 학습자별 성취도 및 오류 빈도 시각화, 개인별 학습 패턴 분석을 통한 맞춤형 학습 콘텐츠 추천.
    산출물: 주차별 학습 참여도 및 성취도 데이터, 코드 오류 유형 및 디버깅 개선 기록, 개인별 피드백 이력)
  4. 사후진단 및 성찰 — 사후 역량 평가⁠(프로그래밍 문제 해결 능력 및 AI 활용 능력), 학습 전⁠·⁠후 비교를 통한 성취도 분석, 자기 성찰 보고서 작성⁠(학습 전략, 개선점 도출) (AI 활용: 사전⁠·⁠사후 데이터 비교 분석을 통한 학습 효과 도출, 학습 과정 데이터 기반 성취도 리포트, 개인별 성장 추이 및 학습 패턴 분석 제공.
    산출물: 사전⁠·⁠사후 비교 분석 보고서, 개인별 학습 성과 및 성장 리포트, 자기성찰 보고서 및 포트폴리오⁠(코드 이력 포함))

주요 주차

  • 1⁠주차 — 강의소개, C 언어 개요 및 기본 구조⁠(대면): 학습자 AI 실습환경 설정
  • 2⁠주차 — 변수와 연산자⁠(혼합형): RAG 기반 문제해결 + 단계별 문제해결 학습, 실습 결과 제출
  • 10⁠주차 — 포인터 개요 및 사용⁠(혼합형): RAG 기반 문제해결 + 단계별 문제해결 학습, 포인터 변수 선언과 간접참조 실습
  • 12⁠주차 — 구조체⁠·⁠공용체⁠·⁠열거형⁠(혼합형): RAG 기반 문제해결 + 단계별 문제해결 학습, 구조체 포인터 실습

AI 도구 구성AI 튜터⁠(학습 지원) ⁠·⁠ 강의실 챗봇⁠(교과목 AI 챗봇) ⁠·⁠ AI 퀴즈⁠(사전학습)
사전 진단전원 LMS 수업 경험 있음, AI 활용 수업 수강 경험자는 없음
  • 단계별 산출물 — 1⁠단계 초기⁠·⁠오류 코드와 시도 기록 → 2⁠단계 AI⁠·⁠교수자 힌트 반영 코드와 전후 비교 → 3⁠단계 최종 코드⁠·⁠최적화 비교⁠·⁠과정 보고서

교육적 효과

  • 정적 LMS 중심의 전통적 실습 수업에서 벗어나 AI 분석 기반의 동적⁠·⁠적응형 실습 구조로 전환.
    코드 작성⁠–⁠컴파일⁠–⁠오류 수정⁠–⁠디버깅⁠–⁠검증 전 과정의 로그를 AI⁠가 분석하여 실시간 피드백 제공
  • 변수 선언 오류, 포인터 사용 실수, 배열 경계 초과, 메모리 관련 오류 등 학습자 개인의 코드 패턴을 분석하고, 난이도 수준⁠(기초 문법 → 포인터 → 동적 메모리 → 구조체 → 파일 처리)⁠에 따라 맞춤형 문제와 힌트 제공
  • 컴파일 성공률, 디버깅 속도, 오류 반복 빈도 등 코드 기반 지표를 실시간 시각화하여 주차별 학습 목표 대비 부족 영역을 즉시 확인.
    문제별 접근 과정, 시도 횟수, 디버깅 패턴, 코드 개선 이력이 학습 포트폴리오로 자동 기록
  • 반복적 코드 피드백을 AI⁠가 처리하여 교수자는 전략 설계⁠·⁠질 관리⁠·⁠개별 면담에 집중 가능.
    피드백의 형평성과 일관성 향상

어려웠던 점

  • C 언어 특성⁠(메모리⁠·⁠포인터 처리, 컴파일 기반)⁠에 따라 AI 피드백이 즉각적으로 정확하게 적용되지 않는 경우 발생.
    동일 문제에 대해 일관되지 않은 답변 제시
  • IDE⁠(Visual Studio Code, Replit 등), LMS, AI 실시간 평가 모듈, 코드 검증 도구 간 통합 미흡.
    한 활동에서 다른 활동으로 이동할 때 환경이 분리되어 학습 효율 저하
  • AI 피드백 반영 기준이 명확하지 않아 학생마다 적용 비율 편차 발생.
    AI 도움을 어느 정도까지 인정할 것인지 명확한 기준 마련 필요

개선 방향

  • AI 피드백 해석법, 프롬프트 작성법, C 언어 디버깅 흐름 등 사전 튜토리얼⁠(AI 도구 활용 가이드) 제공
  • IDE⁠–⁠LMS⁠–⁠LLM⁠–⁠코드 평가 도구가 하나의 플랫폼에서 연동되는 통합 학습환경 구축.
    실습⁠·⁠과제⁠·⁠피드백⁠·⁠평가가 단일 워크플로우에서 처리되는 학습 생태계 요구
  • AI 피드백 반영 비율, 코드 구현 과정 평가, 디버깅 과정 분석을 포함하는 평가 기준 정립.
    결과보다 '⁠과정 중심 평가'⁠를 강화하고 루브릭 기반 평가 체계⁠(이해도, 과정, 결과, AI 활용) 설계
“AI 코스웨어 기반 C 프로그래밍 수업은 초개인화 맞춤학습의 실현, 실습 중심 자기주도적 학습 능력 강화, 데이터 기반 교수 전략의 정교화, 기관 수준의 교육체계 혁신 측면에서 명확한 교육적 성과를 확인할 수 있음.”— 김진환 교수
