# 참가확인증 발급 페이지 (2026 KELI 국제 심포지엄 및 데모데이)

- 주소: https://yoong0520.github.io/keli-site/cert/
- 동작: 성명·소속·이메일 입력 → 발급번호 생성 → A4 확인증 화면 표시 → PDF 내려받기(html2canvas + jsPDF, 브라우저 안에서 생성)
- 서버 없음: 입력 정보는 어디에도 전송·저장되지 않음
- 발급번호: 입력값(성명·소속·이메일, 공백·대소문자 무시)에서 결정되는 6자리. 같은 정보를 다시 넣으면 같은 번호 → 사무국 진위 확인 방법
- 순번(001, 002…)과 발급대장이 필요하면 index.html 상단 APPS_SCRIPT_URL에 Google Apps Script 웹 앱 주소를 넣으면 됨
- 문안·날짜 수정: index.html에서 「2026 KELI 국제 심포지엄 및 데모데이」, 「2026. 10. 20.(화) 10:00–17:00」, 「2026년 10월 20일」 검색
