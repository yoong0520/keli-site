기말 시험에 AI 튜터를 실제 사용한 한림대학교 선형대수학 수강생 31⁠명 ⁠·⁠ 5⁠개 영역 22⁠문항⁠(5⁠점 리커트) + 이용 행태 6⁠문항⁠(객관식) ⁠·⁠ 온라인 자기기입식 설문

보고서 소개

한림대학교 글로컬대학30 사업의 "⁠선형대수학 AI 튜터 학습 데이터를 활용한 AI 튜터 성능 향상 연구"⁠의 6⁠월 정기 리포트다.
5⁠월 리포트가 학생 UX 피드백과 개선 건의 분석에 초점을 맞췄다면, 6⁠월 리포트는 학기 말 설문 응답을 바탕으로 학생이 인지한 학습 효과를 정량적으로 분석한다.

영역별⁠·⁠문항별 평균 점수⁠(5⁠점 만점)⁠와 응답 비율을 산출해 학생이 인지한 학습 효과를 분석했다.
주관식 응답의 텍스트 마이닝은 7⁠월 리포트에서 다룬다.

주요 분석 결과

  • 이용 시간은 "30⁠~⁠60⁠분"⁠이 45.2%(14⁠명)⁠로 가장 많았고, 30⁠분 이상 사용한 학생이 64.5%⁠였다.
  • 활용 목적 1⁠위는 "⁠과제 풀이 중 단계별 힌트 획득" 51.6%(16⁠명), 반면 "⁠거의 이용하지 않음"⁠도 25.8%(8⁠명)⁠로 참여 편차가 있었다.
  • 주요 기기는 태블릿⁠(터치⁠·⁠펜 필기) 74.2%(23⁠명), PC⁠·⁠노트북 16.1%(5⁠명)⁠이며, 가장 많이 쓴 시기는 기말 직전 13⁠~⁠16⁠주차⁠(32.3%)⁠였다.
  • 학습 효과⁠·⁠성취도 인지 영역 평균 3.53⁠점 — 과제 정답률 향상 3.65, 문제해결 시도 증가 3.61, 개념 이해 향상 3.58, 풀이 시간 단축 3.39⁠(최저).
  • 시스템 성능⁠·⁠품질 영역 평균 3.34⁠점으로 5⁠개 영역 중 최저, 수식 인식 일관성은 2.94⁠점으로 유일하게 3⁠점 미만.
    UI 직관성 3.55, 답변 정확도 3.42, 응답 속도 3.35.
  • 오개념 교정 영역 평균 3.55⁠점⁠(자기 수정 유도 3.65, 기술 오류 자체 대처 3.42), 자기주도 학습 영역에서 "⁠자기주도적 학습 자신감" 3.71⁠점이 전 문항 최고, 타 교과목 확장 의향은 3.29⁠점.
  • 영역별 종합: 학습 효과 3.53 ⁠·⁠ 시스템 성능 3.34 ⁠·⁠ 오개념 교정 3.55 ⁠·⁠ 자기주도 3.49, 전 영역 평균 3.48⁠점⁠(5⁠점 만점).

시사점과 제언

  • 자기주도 학습 자신감, 과제 정답률 향상, 오개념 자기 수정 유도 등 핵심 교육 목표에서 긍정적 효과가 확인됐다.
  • 시스템 성능 평균⁠(3.34⁠점)⁠과 수식 인식 일관성⁠(2.94⁠점)⁠이 낮아, 기술 안정성 개선이 학습 효과 추가 향상의 선결 조건이다.
  • 태블릿 사용이 74.2%⁠이므로 팜 리젝션 미지원⁠·⁠필기 인식률 저하 등 모바일 필기 환경 최적화가 핵심 과제다.
  • 기술 오류 시 학생 스스로 대처하는 능력⁠(3.42⁠점)⁠을 높일 안내 자료가 필요하다.
  • 7⁠월 리포트에서 주관식 응답과 강의평가의 텍스트 마이닝으로 개선 우선순위를 정할 예정이다.
